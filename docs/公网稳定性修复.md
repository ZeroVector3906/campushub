## 故障原因与修复

| 原因 | 现场证据 | 修复 |

| 原 Java 实例休眠后的唤醒或入口链路异常 | 02:16:55 最后一次业务验收结束，02:31:55 日志显示正常关闭。之后直接健康请求持续 120 秒未收到内容。03:13:31 再次休眠后，根路径代理、直接请求、浏览器启动入口均未产生 Java 启动日志。日志能把问题定位到应用启动之前，无法进一步确定 Render 内部原因。 | 新建 Oregon 免费实例，验证自动唤醒后将 `/api/*` 切换到该实例。使用现有数据库、账号和会话。 |

## 自然休眠复验

Render 免费实例约 15 分钟无入站流量后休眠。首页由 CDN 继续提供，业务操作需等待 Java 和数据库可用。连接失败时可点击重新连接或打开服务启动页。普通 API 请求截止时间为 12 秒，CSV 为 20 秒。前端先探测健康接口，必要时启用独立启动页和最长 45 秒的健康检查，并在失败后最多自动重试三次。自动恢复仅执行读取，写入结果未知时提示先查记录。 [Render 免费实例规则](https://render.com/docs/free)
