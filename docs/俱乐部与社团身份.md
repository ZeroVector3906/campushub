# 俱乐部与社团身份管理

站名改为「西安欧亚学院征途单车俱乐部&社团」。首页将用户提供的规则整理为两类加入方式，对比体育成绩与发展、部门责任、器材申请和场地限制。体育成绩按学校当学期规定执行，校队与部分赞助按训练和实际安排表述，不承诺自动获得名额或赞助。

## 本次行为

- 成员中心删除「我的俱乐部」统计卡和标签页，保留活动签到、器材借还、维修、个人资料。身份状态仍可在资料区查看；申请撤回或退出入口移至俱乐部展示弹窗，历史记录不删除。
- 注册时必选俱乐部（CLUB）或社团（SOCIETY），填写联系方式、年级和学院。俱乐部可选择课程部、活动部或宣传部作为意向部门。招新开放时注册自动生成待审核申请；关闭招新时仅保存加入意向，可在俱乐部展示确认申请状态。
- 加入选择不授予管理员角色，也不直接授予场地权限。管理员审核通过后，按成员身份开放场地申请；普通成员不能通过个人资料接口改自己的类别、审核状态或部门。
- **器材申请权限按用户后续要求保持不变**：所有正常登录账号仍可按原流程提交器材申请，管理员审核后领取；不因俱乐部/社团身份新增器材限制。库存、借用审批、归还验收规则不变。社团成员仍不得擅自使用室内物品或设施，正式器材借用须走原审批流程。
- 已审核俱乐部成员可申请和光文体中心单车俱乐部或北三骑行室，使用方式支持训练、存车、拿车、维修、休息、其他。社团成员仅可申请北三骑行室存车/拿车；不开放室内训练、维修、休息等用途。特殊情况提前联系管理员，本次未新增例外授权系统。
- 管理员处理待审骑行室申请时再次核对申请人当前身份，避免旧申请绕过新限制。已存在的借还、活动和工单仍保留。

## 后台操作

管理工作台 → 成员管理：可按身份、审核状态筛选或搜索。点击「编辑资料」，编辑姓名、邮箱、学号、学院、年级、联系方式、加入类别、成员审核状态、俱乐部部门和说明。身份调整后场地权限随下一次请求生效，器材申请仍沿用原规则。

管理员权限与启用/停用仍在原权限操作中管理；资料接口不接收角色、启用状态或密码，不重置账号密码。成员 CSV 增加联系方式、年级、身份和部门。

## 数据和 API

Flyway V6 仅新增字段：app_users 增加 join_type/contact/grade，memberships 增加 join_type/club_division。已记录的征途申请联系方式和年级复制到用户资料，不从缺失信息推测类别。旧账号和旧申请标记 UNASSIGNED（待分类），密码、角色、启用状态及旧业务记录保留。管理员确认类别后可正常使用对应场地服务；待分类不会影响原器材申请权限。

- POST /api/auth/register：新增 joinType、contact、grade、clubDivision。
- POST /api/clubs/{id}/applications：新增 joinType、clubDivision；旧客户端未传类别时，仅在用户已有明确加入意向时可沿用。
- GET /api/me/dashboard：新增 member，包含身份、状态、部门与可申请的场所/用途。
- GET /api/admin/users：返回完整可管理成员资料与身份状态。
- PUT /api/admin/users/{id}/profile：管理员更新资料和成员身份，不涉及账号密码与安全角色。

迁移不删除旧列或数据。紧急回退应保留本次身份及场地校验，或先暂停场地申请；直接回退旧程序会失去俱乐部/社团场地限制，不能把数据库字段仍在视为权限兼容证明。原实体名与 JAR 名保持兼容，网站展示名称由新站名统一呈现。
