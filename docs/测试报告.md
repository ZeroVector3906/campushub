## 自动化测试

### 后端：17 项通过

`CampusHubIntegrationTest`：16 项，使用真实 PostgreSQL 测试库、Spring Boot、MockMvc、Spring Security 与 JPA；每项业务数据事务回滚。

- 公开查询不泄露密码哈希和活动签到码。
- 未登录返回 401，学生访问管理接口返回 403，缺少 CSRF 的写请求被拦截。
- 注册密码加密、不能自行注册管理员、非法注册输入被拒绝。
- 社团申请、重复申请拒绝、管理员审核、本人退出、跨用户操作拦截。
- 活动报名名额和重复报名限制。
- 签到的归属、签到码、时间窗口与防重复规则。
- 截止后不能报名，取消活动不能报名。
- 借用批准扣库存、归还验收恢复库存、不能重复归还加库存。
- 多份待审核借用不会提前占库存，审批时不能超卖。
- 器材总量不能减至尚未归还数量以下。
- 维修状态限制与完整处理时间线、个人数据隔离。
- 停用用户立即失去访问权限、不能修改自身权限。
- 中文 UTF-8 BOM CSV、公式前缀转义、统计接口。
- 个人资料与密码更新。

`HttpWorkflowTest`：1 项，启动随机端口的真实 Tomcat，使用 Java HttpClient、独立 CookieJar 与真实 CSRF 令牌，在测试库提交事务，结束时仅清理该测试创建的数据。

该流程实际执行了注册、登录、后台新建社团、入社审核、活动发布、两用户并发抢最后一个名额、所有权校验、错误/正确签到码、器材登记、借用审核、归还验收、工单受理/修复/关闭、CSV 下载、资料修改、密码修改、退出和静态页面/图片访问。

并发报名返回结果为 **一个 201、一个 400**；归还验收后库存恢复为原值；修改密码后两个已登录客户端均返回 **401**，新密码可重新登录。
