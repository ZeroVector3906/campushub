# 超级管理员

角色分为普通用户 STUDENT、管理员 ADMIN、超级管理员 SUPER_ADMIN。超级管理员继承管理员全部日常业务权限，可在「管理工作台 → 成员管理」任免管理员、设置超级管理员、启用/停用账号，编辑所有成员（包括管理员）的姓名、邮箱、学号、学院、年级、联系方式、加入身份、部门、审核状态及意见；编辑框还支持用户名、个人简介与密码重置。

普通管理员仅能编辑普通用户的成员资料，不能任免管理员，不能修改管理员或超级管理员账号资料。公开注册无法选择管理角色。密码只加密存储，不提供明文读取；用户名或密码修改后，目标账号的所有旧会话失效。本人修改用户名或密码后返回登录页。

V7 扩展数据库角色约束；当尚无启用的超级管理员时，将现有默认 admin 管理员升级为超级管理员，不重置密码或其他资料。新数据库首次创建的管理员也为超级管理员。至少保留一名启用的超级管理员，不允许停用或降级最后一人。权限变更和管理员资料写入使用事务锁，用户表仅更新实际修改字段，避免资料保存覆盖并发角色变更。

用途名称统一为「存取车辆」。旧「存车」「放车」「存放车辆」请求继续兼容，历史用途读取统一显示；其他用途和社团器材申请权限不变。

新增 PUT /api/admin/users/{id}/account：仅超级管理员可修改用户名、简介和重置密码。已有 /access 改为仅超级管理员可调用，/profile 按操作者与目标角色检查。用户ID、历史业务关联及系统审计时间保留，不作为普通资料字段重写。

升级后的程序依赖 V7 角色约束；不能直接回退到不识别 SUPER_ADMIN 的旧程序，否则超级管理员将不能访问旧程序的管理接口。保留新角色兼容和授权规则再进行程序回退，不通过删除用户或重置密码回退。
