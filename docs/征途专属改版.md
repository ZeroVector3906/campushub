# 西安欧亚学院征途单车俱乐部网站

本版本针对“西安欧亚学院征途单车俱乐部”，替代原通用多社团平台的展示定位。技术实现继续采用 Java 21、Spring Boot 3.5、Spring Security、Spring Data JPA、PostgreSQL、Maven、Vue 3、Vite、Element Plus。前端和 REST API 打包为同一个 Java 应用，可由现有 Dockerfile 与 Compose 运行。

## 页面与实际业务

| 页面 | 实际功能 |
| --- | --- |
| 俱乐部首页 | 征途品牌、真实业务计数、近期骑行活动、学校报道原文链接、入社指引、器材和报修入口 |
| 俱乐部展示 | 俱乐部简介、招新状态、入社申请、申请状态查询 |
| 骑行活动 | 管理员发布/编辑/取消、筛选、报名、取消报名、签到、活动记录 |
| 成员中心 | 入社审核结果、活动与签到、借还记录、维修进度、资料与密码修改 |
| 器材借用 | 登记器材查询、借用申请、审批、归还与管理员验收、库存校验 |
| 在线报修 | 提交工单、维修时间线、处理进度、管理员工单流转 |
| 管理员后台 | 社团资料与招新管理、入社审核、活动与报名、器材与借还、维修、用户权限、统计与四类 CSV 导出 |

所有站内操作仍调用实际 API；学校报道链接为外部阅读入口。网站注册产生学生角色，管理员审核入社；角色、登录、会话和 CSRF 在后端校验，密码使用 BCrypt 加密。未登录和普通成员不能访问管理员接口。

## 数据与迁移

Flyway V2 归档原八个通用示例社团、取消其示例活动，并停用原六种示例器材；原申请、签到、借还、维修和用户记录不删除。V2 创建征途单车俱乐部。V3 只替换原默认管理员显示名，保留密码、权限和用户自定义姓名。

公共活动和成员数量仅统计运营中俱乐部，旧示例记录不会冒充征途成员或骑行活动。管理员后台默认隐藏归档资料，可勾选“包含归档记录”查看历史。初次展示不虚构真实库存、成员数、路线、集合时间或俱乐部联系方式：正式活动和器材由管理员确认后录入，空状态提供业务入口。

`SEED_DEMO=true` 仅用于本地演示账号；公网保持 `false`。本机旧账号和公网现有管理员继续可用，迁移不重置账号密码。

## 运行、部署与证据

本机双击 `CampusHub.cmd`，或执行 `scripts/start.ps1`。项目名和 JAR 名保留 `campushub`，网站展示名称为征途单车俱乐部。

公网继续使用原 Render 服务与 Neon 数据库，地址不变：https://campushub-2ar9.onrender.com/ 。当前服务使用控制台“Manual Deploy → Deploy a specific commit”部署指定提交；该操作会关闭自动部署。后续更新源码后需手动部署新提交，或先连接 Git 提供方并重新开启自动部署。容器启动时执行新的 Flyway 迁移。管理员用户名仍为 `admin`；首次部署生成的密码位于部署者本机 `.runtime/cloud-admin-password.txt`，此目录不进入 Git、Docker 上下文或源码包。

测试命令：`scripts/build.ps1`（前端组件/逻辑测试、生产构建、真实 PostgreSQL 后端测试与打包）。验收范围与新版截图在完成部署后记录于本文件及对应机器记录；旧 `cloud-verification.json` 是原通用版本的历史记录，不能替代本次验收。

### 本地实际结果

2026-11-07：简介版前端 16 项测试与生产构建通过；Java 后端 19 项真实 PostgreSQL 测试通过，包括真实 HTTP 业务链路、并发名额、密码与会话撤销、归档迁移保留历史和统计隔离。修正 HTTP 测试中两次取时导致的偶发报名截止时间误差；实际业务时间校验未放宽。Edge 本地已检查真实照片、标识、俱乐部展示与申请弹窗。

V4 仅更新征途简介和一句话介绍，不改密码、权限、历史记录或器材库存。专业训练、五项历史实践与合作支持按简介分区展示；过往活动不会生成可报名的新活动。
