# 素材与依赖

征途新版首页与展示页采用用户提供的俱乐部简介中的真实照片和标识，来源及页码见《简介内容整理.md》。所选素材存放于 `frontend/public/images/`，运行时无需访问外部图片服务。

站点图标为本项目 SVG，业务图标来自 Lucide；俱乐部展示页的学校与俱乐部标识来自用户提供的简介。历史摄影素材使用范围以 [Unsplash 授权](https://unsplash.com/license) 为准。

主要开源依赖：Spring Boot / Spring Security / Spring Data JPA / Spring Session、PostgreSQL JDBC、Flyway、Vue、Vue Router、Element Plus、Lucide、Vite、Vitest、Vue Test Utils、Happy DOM。准确版本由 `backend/pom.xml` 与 `frontend/package-lock.json` 固定；许可证和版权以各依赖发布内容为准。
